# Для Анастасии ❤️

Личный сайт-письмо с семью фотографиями, извинениями, пятью вопросами и предложением выбрать дату и время разговора.

## Публикация (GitHub Pages)

В репозитории открой **Settings → Pages → Build and deployment → Deploy from a branch** и выбери **main / (root)** → **Save**.

После публикации адрес сайта: https://chemax1710.github.io/for-anastasia/

## Как приходят ответы

Сайт работает **без базы данных**. Ответы на опрос и выбранное время автоматически **никуда не передаются и не сохраняются**. На финальной странице Анастасия увидит готовое сообщение; чтобы оно дошло, ей нужно нажать **«Открыть WhatsApp и отправить»**, выбрать чат с Максимом и самой отправить сообщение. Можно также скопировать текст.

## Приватность

Репозиторий и GitHub Pages публичные. Совместные фотографии встроены в `index.html` и доступны посетителям. Не размещайте приватные данные.

Для будущего автоматического сбора ответов потребуется отдельный сервер или сервис хранения данных и согласие Анастасии на отправку.
